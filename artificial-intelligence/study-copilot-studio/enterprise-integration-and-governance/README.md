# Enterprise Integration & Governance

Group 7 of the Copilot Studio course: who's allowed to build and run an agent, what it's allowed to touch, and how it moves safely from a maker's desk into production.

* **7.1 — Identity and Security** — agent-level authentication, the automatic security scan, Entra Agent ID provisioning, and data loss prevention policies
* **7.2 — Responsible AI** — core principles, safety filters, human oversight, the Copilot Studio System/Application Card
* **7.3 — ALM Foundations** — solutions as ALM containers, environment strategy, environment variables
* **7.4 — ALM Automation** — CI/CD pipelines (Power Platform pipelines, Azure DevOps, GitHub Actions) and a closing governance review
